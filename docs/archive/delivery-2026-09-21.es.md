## Qué falta para usar datos reales y publicar

1. Configurar `TWELVE_DATA_API_KEY` en el servidor, validar símbolos y cuotas con una cuenta real. El adaptador ya está implementado y sus contratos se probaron con HTTP simulado.
2. Habilitar escritura del conector GitHub sobre `ea-inversion`. La creación de la rama devolvió HTTP 403, `Resource not accessible by integration`; no se subieron cambios ni se abrió PR. No se modificó `main`.
3. Elegir y validar un despliegue con HTTPS, base persistente y backups. El README separa los límites de este MVP de los requisitos de producción.

La CI está incluida, pero no se ha ejecutado en GitHub debido al bloqueo de escritura. PostgreSQL es una opción de configuración no comprobada contra un servidor real en esta entrega.
